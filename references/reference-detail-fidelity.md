# 截图还原的局部细节判断

在 recreate 分析及最终视觉检查时读取。原图局部特征属于还原要求，不能以组件默认样式替代。

- 判断真实轮廓：矩形、圆角、六边形、票券切角、锯齿或手撕边，是否左右不对称，是否有局部凹口。放大观察，不因缩略图模糊而默认普通矩形。
- 判断位置关系：倾斜角度、遮挡顺序、越界幅度、贴纸与卡片的重叠、对齐和留白。
- 判断视觉细节：色值、描边、阴影、字重、字体、字号、行高和文字在轮廓内的偏移。
- 例如本任务的 Selling Fast 是橙黄色票券贴纸：略微倾斜，边缘有不规则齿口与凹缺，压在紫色卡片上；不能仅用旋转的规则矩形近似。
- 简单几何与贴纸轮廓使用可编辑矢量 / SVG path，文字单独保留为可编辑文本；网页使用组件与 CSS / SVG。不要为此生成包含文字的扁平图片，也不为了套用组件库抹去轮廓。
- 素材内部细节交给参考图驱动的高清流程，图标复用统一图标系统；装饰轮廓与功能图标分开判断。
- 对照原图与最新渲染逐项检查实际出现的特征；只修正有依据的差异，不添加原图没有的齿口、纹理或阴影。

## 纵向节奏与素材内部留白

- 完整页面验收必须检查标题、装饰线、插画、说明与主按钮之间的纵向节奏；不要只确认没有重叠或溢出。
- 区分容器边界与可见主体边界：透明 PNG / SVG 画布内部可能含大块留白，不能把画布尺寸直接当主体尺寸，再重复加 margin / padding。
- 类似下载卡片应形成连续阅读路径：标题 → 插画 → 简短说明 → 按钮。出现无目的大空档时，检查固定高度、图片内部透明边距、object-fit / FIT、重复 margin 与绝对定位；优先消除叠加留白。
- 根据实际主体适度裁切空白或调整展示尺寸与间距，保留完整线条与装饰，不为紧凑而切掉主体。需要修改位图时按适用图像编辑技能执行。
- 新设计 / 优化任务可按内容收紧卡片高度；忠实还原任务先对比原图。用户明确指出间距过大时视为授权局部优化，不以默认截图还原规则拒绝调整，也不扩展到无关页面。
- 在实际显示尺寸和手机视口上看整块内容，而不是只看局部截图；记录仍未应用到 Figma 的修改，不把网页改善说成 Figma 已更新。
